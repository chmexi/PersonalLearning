## Variant: Guided Flow

### Design stance
One exercise at a time, full-screen focus. Steps through the training sequentially with timer and progress dots.

### Key choices
- **Theme**: Dark mode (#1A1B2F), gradient cards
- **Layout**: Single exercise view with timer, bottom summary strip
- **Interaction**: Start → Timer countdown → Record/Write → Next
- **Progress**: Dot indicators at bottom + full list collapsed below
- **Timer**: Visual circle countdown, start/skip controls

### Trade-offs
- **Strong at**: Deep focus — only one thing on screen at a time
- **Weak at**: Can't see all exercises at a glance; more taps to navigate

### Best for
Users who want a guided, step-by-step practice session without distraction
