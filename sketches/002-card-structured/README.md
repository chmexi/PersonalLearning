## Variant: Card Structured

### Design stance
White cards on light gray background — each exercise is a distinct visual block. Feels more like a task management app.

### Key choices
- **Theme**: Light mode, white cards on #F5F5F5
- **Typography**: Bold titles, colored icon badges per exercise type
- **Layout**: Card per exercise with shadow, checkbox for completion
- **Interaction**: Checkbox to mark done, tap card to start
- **Streak**: Badge style in header

### Trade-offs
- **Strong at**: Clear separation between exercises, satisfying check-off
- **Weak at**: More visual noise, less "focused" feeling
- **Strong at**: Gamification (streak badge, progress bar, checkboxes)

### Best for
Users who respond well to visual progress tracking and clear task separation
